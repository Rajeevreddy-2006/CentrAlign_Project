# Project Documentation

This directory contains technical design documents, architectural diagrams, task specifications, and verification protocols for the Autonomous AI Task Worker.

## Directory Structure
- `architecture.md`: Detailed agent loop, state machine, memory model, and tool interfaces (to be added in Milestone 2).
- `verification_protocol.md`: Standards for verifying task completion with tamper-evident artifacts.
- `simulated_environment.md`: Specifications for the simulated business portal and test invoices.
